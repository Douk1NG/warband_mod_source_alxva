# Bandit System

Changes to bandit, lair, manhunter, pirate, and deserter behavior.

## Bandit Parties
- Max 50 troops per party, capped at 20 when lair is destroyed
- Max 18 parties per type — recovers 1/day if below cap

## Lairs
- Destroy: 3 day cooldown
- Lose: 24h cooldown, respawns at new spot

## Manhunters
- Fixed at 24 parties
- Tougher: slave drivers, hunters, crushers in the mix
- Faster only when chasing
- Can buy their bandit prisoners through dialog

## Pirates
- 3 ship types, 5 parties each, 20 crew per ship

## Deserters
- Free recruit if you outmatch them + 500 renown

## Debug Tools (Cheat Mode)
Reports → Cheat Reports: bandit population diagnostics (cooldowns, lair status)
Cheat → World: remove all bandits, remove all ships, show all bandit lairs
