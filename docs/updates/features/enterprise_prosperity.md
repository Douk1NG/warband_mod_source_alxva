# Enterprise Prosperity Scaling

Town enterprises now scale production and profit based on local prosperity.

## What changed
- Poor towns (prosperity <30): ×0.5 production
- Very rich towns (prosperity ≥90): ×2.0 production
- Enterprises buy raw materials at cheapest local/imported price
- All 9 enterprise types retuned for ~25-week payback
- Operating enterprises boost host town prosperity (+1 + floor(Trade/5))
- Town merchants stocked with produced goods based on Trade skill
