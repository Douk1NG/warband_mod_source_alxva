# Auto Upgrade Troops

Automatically upgrades troops in your party after battles and training based on a configurable mode.

## Configuration
Toggle in Settings → XGM Mod Options → Auto Upgrade.

## Modes
- Off: disabled
- Balanced: splits each troop stack evenly between available upgrade paths
- Infantry: upgrades toward infantry path, falls back to first path
- Archers: upgrades toward archer path, falls back to first path
- Cavalry: upgrades toward cavalry path, falls back to first path

## Behavior
- Only upgrades troops with enough XP
- Gold deducted from player personal gold
- Triggers after field battles, siege victories, training ground, and at midnight (daily)
