# All Items Browser

An all-items browser accessible from the reports menu showing every purchasable item in the game.

## Access
Reports → All Items.

## Usage
- Browse items by category (weapons, armor, horses, etc.) using the category selector
- Paged grid — 56 items per page, 8 columns
- Click an item to preview it in the preview pane
- Hover over any item to see its stats and skill requirements

## Cheat Mode
When cheats are enabled:
- Quality selector — choose the item modifier (Plain, Fine, Masterwork, etc.)
- Quantity input — set how many items to add (1–99)
- Get button — adds the items with the selected modifier to your inventory
