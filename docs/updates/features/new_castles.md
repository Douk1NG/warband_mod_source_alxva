# New Castles

22 new castles added across all six factions. Each castle has an exterior scene, interior scene, prison scene, and a seneschal NPC. Castles are assigned to factions and specific lords at game start.

## Distribution

| Faction | Castles |
|---------|---------|
| Swadia | Deglan, Tredian, Ryis, Stamar, Tshibtin, Yalibe |
| Rhodoks | Saren, Reland, Falsevor, Reichsin |
| Vaegirs | Doru, Gastya, Uslum |
| Khergit | Sebula, Rduna |
| Nords | Turegor, Rayeck, Aldelen |
| Sarranid | Ghulassen, Muhnir, Biliya, Sekhtem |

Three castles (Tshibtin, Yalibe, Rduna) have belfry siege capability.

**Note:** Requires `.sco` scene files to be present in the module for the game to load properly.
