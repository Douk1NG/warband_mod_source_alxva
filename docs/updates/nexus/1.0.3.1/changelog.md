# Version 1.0.3.1

## Added

- New UI inspired by PoP. It must be enabled manually. To restore the previous
  UI, restore these DDS files: `bg2`, `interface`, `quests_window`, `ui`,
  `user_interface_b`, `note_window`, `dialogue_window`, `character_window`,
  `face_gen_window`, `button_drop`, `cb_ui_comp`, `inventory_window`,
  `party_window`, and `escape_menu`. Also restore `game_variables_old`.
- Camp Hub: camp opens a custom hub for settings, actions, waiting, walking,
  and cheats.
- Bandit Overhaul settings for party limits, base size, respawn interval, and
  parties spawned per interval for each bandit family.
- Companions are assigned battle groups based on horse or bow equipment unless
  manually assigned.

## Fixed

- Native auto-upgrade and Camp Hub opcode errors.
- All Items browser filtering.
- Companion inventory and equipment-screen navigation.
- Autoloot and auto-upgrade edge cases.
