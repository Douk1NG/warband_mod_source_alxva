# Unit Progression and Branching Tree

This document outlines the hierarchical branching structure and progression path for units, starting from a base recruit and advancing through various specialized branches and quality tiers.

*Note: `*`, `**`, and `***` represent unit quality tiers (e.g., Bronze/Silver/Gold or Tier 1/2/3).*

---

## Structure Overview

```
Recruit Branch (A)
 ├── Infantry Branch (B.1)
 │    ├── Infantry A (C.1) -> Infantry A ** (D.1) -> Infantry A *** (E.1)
 │    └── Infantry B (C.2) -> Infantry B ** (D.2) -> Infantry B *** (E.2)
 │
 ├── Cavalry Branch (B.2)
 │    ├── Cavalry A (C.3) -> Cavalry A ** (D.3) -> Cavalry A *** (E.3)
 │    └── Cavalry B (C.4) -> Cavalry B ** (D.4) -> Cavalry B *** (E.4)
 │
 └── Archer Branch (B.3)
      ├── Archer A (C.5) -> Archer A ** (D.5) -> Archer A *** (E.5)
      └── Archer B (C.6) -> Archer B ** (D.6) -> Archer C *** (E.6)
```

---

## Detailed Breakdown by Stage

### 1. Initial State
* **Branch A:** Recruit Branch (Starting point)

### 2. Primary Specialization Branches (Stage B)
From the initial recruit, units branch into three main tactical classes:
* **Infantry Branch (B.1)**
* **Cavalry Branch (B.2)**
* **Archer Branch (B.3)**

---

### 3. Sub-Specializations & Quality Progression (Stages C, D, E)

#### Infantry Path (B.1)
* **Infantry A Sub-branch:**
  * **C.1 (Infantry A *):** Initial Infantry A specialization.
  * **D.1 (Infantry A **):** Mid-tier upgrade.
  * **E.1 (Infantry A ***):** Elite-tier upgrade.
* **Infantry B Sub-branch:**
  * **C.2 (Infantry B *):** Initial Infantry B specialization.
  * **D.2 (Infantry B **):** Mid-tier upgrade.
  * **E.2 (Infantry B ***):** Elite-tier upgrade.

#### Cavalry Path (B.2)
* **Cavalry A Sub-branch:**
  * **C.3 (Cavalry A *):** Initial Cavalry A specialization.
  * **D.3 (Cavalry A **):** Mid-tier upgrade.
  * **E.3 (Cavalry A ***):** Elite-tier upgrade.
* **Cavalry B Sub-branch:**
  * **C.4 (Cavalry B *):** Initial Cavalry B specialization.
  * **D.4 (Cavalry B **):** Mid-tier upgrade.
  * **E.4 (Cavalry B ***):** Elite-tier upgrade.

#### Archer Path (B.3)
* **Archer A Sub-branch:**
  * **C.5 (Archer A *):** Initial Archer A specialization.
  * **D.5 (Archer A **):** Mid-tier upgrade.
  * **E.5 (Archer A ***):** Elite-tier upgrade.
* **Archer B Sub-branch:**
  * **C.6 (Archer B *):** Initial Archer B specialization.
  * **D.6 (Archer B **):** Mid-tier upgrade.
  * **E.6 (Archer C ***):** Elite-tier upgrade *(Note: transitions/evolves into Archer C at max quality).*
