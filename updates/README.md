# Updates

This folder contains sequential update summaries for the module source.

## Current entries

- `update-00#.md` — [action] [title]
  - Includes file-by-file, line-by-line explanations for the cleanup of unused script parameters, redundant logic, and the build notice noise reduction.

## Usage

Add each new update as a separate markdown file in this folder, using the next sequential number in the name (`update-002.md`, `update-003.md`, etc.).

Each file should include:

- A short title
- A purpose section
- A detailed list of file changes
- Notes describing why the change was made and whether it is maintenance-only or behavior-affecting
